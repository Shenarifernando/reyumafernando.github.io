REYUMA FERNANDO — SOFT LUXURY PORTFOLIO

OPEN
1. Extract this ZIP file.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Keep the assets folder next to index.html.

EDIT / REPLACE MEDIA
- Replace assets/creator-video.mp4 with your new MP4 video. Keep the same filename.
- Replace assets/reyuma-portrait.jpg to update the main portrait.
- Replace assets/reyuma-cutout.png to update the transparent cut-out image.
- To add another video, copy the video-card block in index.html and change the filename in its <source src="assets/..."> line.

IMPORTANT
- The HTML website is editable. You can use a text/code editor such as VS Code or Notepad.
- The PDF is a static application attachment; it does not play videos.
- If you share the website online, upload the entire extracted folder (index.html AND assets), not just index.html.
